# Redis-Like In-Memory Key-Value Store
A Redis-inspired in-memory key-value server built from scratch in C++ to explore database internals, networking, and client-server communication.

# Project Status
Currently under development.

# Overview
This project aims to implement a lightweight Redis-inspired server that handles client requests over TCP connections and provides in-memory key-value storage.
The goal is to understand how in-memory databases work internally, including network communication, request processing, and data management.

# Tech Stack
- Language: C++
- Networking: TCP Sockets
- Version Control: Git & GitHub

# Implemented Features
Protocol parsing and request partitioning.

# Currently Working On
Event loop implementation.
Non-blocking I/O for handling client connections.

# Planned Features
- Command parsing and execution
- Key-value storage operations

# Motivation
Built as a hands-on systems programming project to strengthen understanding of C++, computer networks, and database architecture.
